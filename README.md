# Morni Wolkenkampf

Der Insel-Kampf-Modus des Minecraft-Netzwerks **MoinMorni** (moinmorni.net): Jeder startet in einer Ballon-Gondel über
einer eigenen kleinen Insel in den Wolken – Truhen plündern, Brücken bauen, kämpfen. Wer zuletzt noch steht, gewinnt.

Englischer Name: **Cloud Clash**. Ein Paper-Plugin für Paper 26.x (Java 25), im Netzwerk und auch ganz allein.
